# 荧光笔下划线标题

点名“荧光笔下划线标题”“绿色下划线强调”“双端互通同款标题”或 `marker-underline-title` 时读取本文件，使用 [下划线逐帧实现](../assets/effects/marker-underline.mjs)。参考字形匹配的是本包新增的**站酷庆科黄油体**，常规400字重；按 [字体说明](fonts.md) 实际载入。字体可独立调用，用于其他标题文字。

## 形态与动作

参考可见窄长圆角黑字，底部一条宽的薄荷绿色带，色带覆盖字形下部约20%–30%，在字层后方，四字标题整体显现。这里把“下划线”实现为荧光笔式底色带，色带厚度约0.25倍可见字高，左右各超出文字约0.04倍字高。文字本身保持锐利。

用户需要划线动作时，默认色带在标题出现后约0.08秒开始，0.30秒从左往右划出，完成后保持。实现的 `mode='draw'` 对应此动作，`mode='fade'` 对应参考可见的整体渐显形态。标题可在0.15–0.20秒淡入，按本期指令选用。色带颜色、填充不透明度、厚度、起止位置与绘制时间均可覆盖。绿色起始值为 `#63D69B`，填充不透明度0.85。

文字、下划线分层，底色带先绘制，字层后绘制。先等待真实字体载入，再测量可见字形或文本范围，以测量结果定位色带。更换文字、字体、字号或换行后重新测量。多行标题逐行定位，避免一条整段色块穿过行间。字体只用于标题时，可让密集正文继续用其适合的正文字体。

## 接入

复制模块到工程后，从主时间轴传入秒数。下面的 `box` 是已经测量得到的色带范围。

```jsx
const underline = getMarkerUnderline({
  time: frame / fps,
  start: 0.58,
  end: 3.5,
  box: {x: 690, y: 360, width: 540, height: 30},
  color: '#63D69B',
  fillOpacity: 0.85,
  drawSeconds: 0.3,
  mode: 'draw',
});
// In the same SVG, render the underline first, then the loaded-font text.
// {underline && <rect {...underline} />}
```

HTML/HyperFrames使用同一属性与时间算法，`fillOpacity`转换为SVG的 `fill-opacity`。运动由主时间轴驱动。登记 `marker_underline` feature，并登记标题文本、实际字体文件、字级、色带位置与时间。

## 调用与验收

调用示例“调用CutStation，标题‘双端互通’使用参考同款字体，配荧光笔下划线标题，薄荷绿底色带从左向右划出，停留2秒。”字体单独使用可说“这条视频的章节标题沿用‘双端互通’同款字体，文字改为‘自动生成’，不加下划线”。颜色示例“色带改为淡紫色，不透明度70%，用0.4秒划出”。

核对实际字体字形、文字内容、标题首中尾帧、色带首中尾位置、叠层与文字可读性。更换最长标题测试字宽和画布安全区。预览/导出都应能看到绘制过程，完整标题阅读时间从划线结束后计算。
